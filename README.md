# Vani.Coach — Assessment Results

A mobile assessment dashboard built with **React Native, Expo, and TypeScript**. This project presents assessment results in a clean, easy-to-navigate interface, helping users review their performance and track their progress.

## Features

- **Assessment dashboard** — View assessment questions, assessment types, statuses, scores, and feedback.
- **Progress overview** — Track completed assessments, average score, and completion rate.
- **Status filters** — Filter assessments by All, Upcoming, Completed, or Pending.
- **Search** — Find assessments by their question or related text.
- **Sorting** — Sort assessments by most recent, highest score, or lowest score.
- **Performance feedback** — Display feedback for completed assessments, with results categorized as Good or Needs Improvement.
- **Upcoming and pending states** — Clearly distinguish assessments that are not yet completed.
- **Empty states** — Handle cases where no assessments match the selected filter or search.
- **Reusable UI components** — Maintain a consistent layout across assessment cards and dashboard sections.

## Tech Stack

- React Native
- Expo
- TypeScript
- Expo Router

## Getting Started

### Prerequisites

- Node.js
- npm
- Expo Go or a compatible development environment

### Installation

Clone the repository:

```bash
git clone https://github.com/MUSTAFA786ALI/vani-assessment-results.git
cd vani-assessment-results
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npx expo start
```

Follow the Expo CLI instructions to open the app in Expo Go, an emulator, or a simulator.

- `src/app/index.tsx` — Assessment results screen and dashboard interactions.
- `src/app/_layout.tsx` — App navigation and layout configuration.
- `src/data/assessments.ts` — Assessment types, sample records, statuses, scores, and feedback.

## Sample Data

The dashboard currently uses **15 sample assessment records**, including completed, pending, and upcoming assessments. Scores and feedback are illustrative data used to demonstrate the interface; they are not generated by a live AI service.

The current performance classification uses a score threshold of **70**:

- **Good:** Score of 70 or above.
- **Needs Improvement:** Score below 70.
